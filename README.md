# ❤️ Heart Disease Predictor

KNN-based heart disease prediction with a Streamlit app.

🔗 **[Live Demo](https://heart-disease-predictor-k7su24wgyzkxr5nzeilenq.streamlit.app/)**

## Overview

This project uses a KNN classifier to predict heart disease risk based on patient health parameters. The trained model is deployed using Streamlit for interactive predictions.

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
- Jupyter Notebook
  
## Workflow

Dataset
→ Data Cleaning
→ Exploratory Data Analysis
→ Encoding
→ Feature Scaling
→ KNN Classification
→ Model Evaluation
→ Streamlit Deployment

## Model

A K-Nearest Neighbors (KNN) classifier was trained to predict whether a patient is at risk of heart disease.

The project also uses `StandardScaler` for scaling numerical features and saved preprocessing/model files for use in the Streamlit application.
